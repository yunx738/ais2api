配置 AI Studio 应用




    

  1. 用任意一个已加入账号池的 Google 账号打开 aistudio.google.com/apps，点 Build 新建一个空白应用。
    2. 

  2. 在左侧文件中打开入口脚本（通常是 index.tsx 或 index.js），删除全部内容。
    3. 

  3. 点下方“复制客户端脚本”，粘贴进去并保存。脚本连接地址保持 ws://127.0.0.1:9998 不变。
    4. 

  4. 右侧预览出现 [ProxyClient] 开头的日志即表示脚本已运行；断开连接的报错可忽略。
    5. 

  5. 点右上角 Share，访问权限设为 Anyone with the link，账号池里的其他账号才能打开。
    6. 

  6. 复制浏览器地址栏中的链接，格式为 https://ai.studio/apps/xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx，填入下方并保存。
    7. 

  7. 点“立即生效”，两个实例会依次换号重启并加载新应用；不点则在下次换号时生效。
    8. 



应用链接只保存在服务器上，不会写入代码仓库。不要把链接公开，被删除或改为私有后需要重新配置。
